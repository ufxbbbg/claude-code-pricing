## 两条付费路线，先分清

Claude Code 是 Anthropic 的编程代理，装在终端或 IDE 里，读代码、改文件、跑测试、开 PR。它的计费和聊天版 Claude 绑在同一套账号体系里，所以先分清两条路线：

- **订阅制**：Pro、Max、Team、Enterprise 套餐都包含 Claude Code，交互式使用不按 token 另收钱，但受用量限额约束。

注意 Free 套餐（$0）只有聊天和普通代码生成，不包含 Claude Code。想免费用它，目前没有正规途径。

## 订阅最该搞懂的一点：5 小时窗口和每周限额

订阅不是无限用。限额有两层：一个 5 小时滚动的会话窗口，加一个每周限额，两层都和聊天共用。

实际体验因人而异。thehype.news 收集的重度用户反馈里，有人用 Pro 在多仓库之间协调编辑，30 分钟就烧完了一个 5 小时窗口；Max 20x 的用户反而更多先撞上周限额，有人周日重置后到周二早上就用掉 86%。作为参照，测评口径下 Pro 大约对应每周 10 到 20 次专注编码会话。

好消息是限额在往宽里走：2026 年 5 月 6 日，Anthropic 把 Pro、Max、Team 的 5 小时限额翻倍，并取消了高峰期的额度缩减；9 月 22 日随 Opus 5.5 上线又上调过一轮，之后开始出现“一整天编码只用掉周额度 10%”这类反馈。

撞墙了也有缓冲：Pro 和 Max 可以开启 usage credits，超限部分按 API 费率继续跑，月度花费上限自己设。

## API 按量计费：每个模型多少钱

不订阅、直接用 API Key 的话，按下面的单价结算（每百万 token）：

| 模型 | 输入 | 输出 | 缓存读取 |
| --- | --- | --- | --- |
| Fable 5.1 | $10 | $50 | $0.25 |
| Opus 5.5 | $4 | $20 | $0.20 |
| Sonnet 5 | $2 | $10 | $0.20 |
| Haiku 4.5 | $1 | $5 | $0.10 |

三个直接影响账单的因素：

1. **提示缓存**。Claude Code 的工作流里大量输入是重复上下文，命中缓存后按表中的缓存价结算。thehype.news 9 月底的实测里，Opus 5.5 跑完一个 Python 命令行小任务用了 2 分 32 秒，折算 API 成本 $0.73，其中 94% 到 98% 的输入都来自缓存，这也是它比 Sonnet 还便宜的原因。
2. **Batch API 半价**，适合不赶时间的批处理任务。
3. **tokenizer 变化**。Opus 4.7 之后的新模型，同一段文本可能比旧模型多产出最多约 35% 的 token，做预算时留点余量。

Anthropic 给企业客户的参考值是：约 $13 每开发者每个活跃日，月支出 $150 到 $250，90% 的用户每天不到 $30。hokai.io 的测评则估算，订阅制下全职重度使用平均约 $6 每开发者每天，对应每月 $100 到 $200。

还有一个容易莫名其妙的坑：如果 shell 环境里设了 ANTHROPIC_API_KEY，Claude Code 可能绕开订阅直接按 API 扣费。账单不对劲时，先跑一下 /status 检查。
